# Adult Human Cortex Single-Nucleus RNA-seq Analysis

This repository contains the analysis scripts used to process, annotate, compare, and genetically interpret adult human cortex single-nucleus RNA-seq data across cortical regions. The workflow starts from 10x Genomics Cell Ranger output, performs quality control and cell annotation, quantifies cell-type composition across regions, compares regional transcriptomic similarity, integrates human and mouse excitatory neuron datasets, evaluates cross-region reproducibility with MetaNeighbor, and prepares/visualizes GWAS enrichment results using CELLEX/CELLECT-MAGMA.

## Repository structure

```text
.
├── 1.1_preprocess_scanpy.py
├── 1.2_process_annotate_seurat.r
├── 1.3_cluster_fractions_across_regions.r
├── 1.4_region_correlation.r
├── 1.5_integrate_region_across_species.r
├── 1.6_metaneighbor_analysis.r
├── 1.7_GWAS_1.py
├── 1.8_GWAS_2.r
├── Data/                  # raw 10x matrix, sample metadata, intermediate h5ad files

├── Fig1/                  # output folder for Figure 1 panels
└── Figures/               # output folder for other manuscript figures
```

The scripts are numbered in the intended execution order. Some downstream scripts depend on outputs generated by earlier scripts.

## Required software

The code uses both Python and R.

### Python

Recommended Python version: Python 3.8 or later.

Required Python packages:

```bash
pip install scanpy numpy pandas matplotlib bbknn scrublet cellex
```

Depending on your environment, `scanpy` may also require packages such as `anndata`, `h5py`, `scipy`, `scikit-learn`, `umap-learn`, `leidenalg`, and `igraph`.

### R

Recommended R version: R 4.1 or later.

Required R packages:

```r
install.packages(c(
```

## Workflow overview

### 1. Preprocess raw single-nucleus data with Scanpy

```bash
python 1.1_preprocess_scanpy.py
```

This script reads the 10x matrix, calculates QC metrics, merges sample metadata, removes low-quality cells and predicted doublets, performs normalization and highly variable gene selection, constructs a BBKNN batch-corrected graph, runs UMAP and Leiden clustering, removes manually identified low-quality clusters, and exports metadata for Seurat.

Main outputs:

```text
./Data/raw_v1.h5ad
./Data/HC_HVG2000_v1.h5ad
./Data/HC_HVG2000_filt_lowQualityCluster.h5ad
./Data/HC_HVG2000_metadata.csv
```

### 2. Integrate and annotate cells with Seurat

```bash
Rscript 1.2_process_annotate_seurat.r
```

This script imports raw counts into Seurat, adds the Scanpy-derived metadata, integrates samples across cortical locations, clusters cells, and performs manual annotation of excitatory neuron subclasses. The inhibitory neuron and non-neuronal annotation steps should follow the same logic and must generate `ch.In` and `ch.Nn` before the final metadata merge.

Main outputs:

```text
./data/All_region_cortex_seurat_Exc.rds
./data/All_region_cortex_seurat_v1.rds
```

Important note: the uploaded original script contains references to `ch.In`, `ch.Nn`, `ch.integrated.sub.sub`, and `gastrul_colors_37` that are expected to be created or defined in the full analysis environment. They are documented in the annotated script, but users should define them before running the final merge section.

### 3. Calculate broad cell-class proportions across regions

```bash
Rscript 1.3_cluster_fractions_across_regions.r
```

This script calculates the fraction of glutamatergic, GABAergic, and non-neuronal cells within each anatomical region and sample/location, then plots mean proportions across regions.

Output:

```text
./Fig1/Class_prop.pdf
```

### 4. Compute regional correlation of excitatory subclasses

```bash
Rscript 1.4_region_correlation.r
```

This script identifies top marker genes for each excitatory subclass, calculates average expression across cortical regions, computes pairwise regional correlations, and summarizes these values as heatmaps.

Input:

```text
./data/All_region_cortex_seurat_Exc.rds
```

### 5. Integrate human and mouse excitatory neurons

```bash
Rscript 1.5_integrate_region_across_species.r
```

This script integrates human frontal-lobe excitatory neurons with mouse frontal-region glutamatergic neurons, visualizes the integrated embedding, compares human and mouse cluster labels, and plots subclass proportions.

Outputs:

```text
./Figures/Human_mouse_cluster_label_corrplot_FL.pdf
./Figures/Human_mouse_prop_FL.pdf
```

Important note: the original script used `mouse_exc`, `cluster_level`, and `source` without defining them explicitly. The annotated version defines or documents these fields, but users should still confirm that the metadata names match their local Seurat objects.

### 6. Run MetaNeighbor cross-region reproducibility analysis

```bash
Rscript 1.6_metaneighbor_analysis.r
```

This script converts the final Seurat object to a `SingleCellExperiment` object and performs MetaNeighbor one-vs-one analysis to assess whether cell subclasses are reproducible across cortical regions.

Outputs:

```text
./data/All_region_cortex_v1_sce.rds
./Figures/Exc_MainLoc_Celltype.pdf
```

### 7. Generate CELLEX specificity scores for GWAS analysis

```bash
python 1.7_GWAS_1.py
```

This script calculates expression specificity scores for each region-by-cell-subclass label using CELLEX. The resulting files can be used as input for CELLECT-MAGMA.

Output prefix:

```text
./data/MainLoc_clusters2_v1_human_brain_cells
```

### 8. Visualize CELLECT-MAGMA GWAS enrichment results

```bash
Rscript 1.8_GWAS_2.r
```

This script reads CELLECT-MAGMA prioritization results, computes enrichment statistics, adjusts P values, adds significance annotations, and generates a heatmap across selected GWAS traits and region-by-cell-type labels.

Output:

```text
./Figures/GWAS_heatmap.pdf
```

## Reproducibility notes

1. Set random seeds before downsampling or clustering if exact reproducibility is required. For example, use `set.seed(123)` in R before `sample()` or `sample_n()`, and `np.random.seed(123)` in Python before stochastic operations.
2. The QC thresholds in script 1.1 are dataset-specific: cells are retained if they have 600 to 10,000 detected genes and mitochondrial fraction below 20%.
3. The removal of Leiden clusters `17` and `5` in script 1.1 is a manual quality-control decision and should be justified by QC plots and marker inspection.
4. Manual cluster-to-cell-type annotation in script 1.2 should be supported by canonical marker genes and, when possible, by supplementary marker tables.
5. Some paths use `Data/` and others use `data/`. On case-sensitive systems such as Linux, these are different directories. Keep the directory names consistent or update paths accordingly.

## Suggested citation and data availability text

The raw and processed data, metadata tables, and analysis code should be made publicly available before publication. A data availability statement can use the following structure after replacing placeholders with the actual accession numbers and URLs:

> Raw sequencing data have been deposited in GEO under accession number `GSEXXXXXX`. Processed AnnData/Seurat objects and cell-level metadata are available at `[repository URL]`. Analysis scripts are available in this GitHub repository together with a README describing software dependencies, required inputs, and step-by-step execution instructions.
