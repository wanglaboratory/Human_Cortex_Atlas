# snRNA-seq and Spatial Transcriptomics Integration

This repository contains a Python script for integrating adult human frontal-lobe single-nucleus RNA-seq (snRNA-seq) data with frontal-lobe spatial transcriptomics data. The workflow performs cross-modality integration, transfers snRNA-seq cell-type labels to spatial cells/spots, and imputes spatial gene expression from nearest snRNA-seq neighbors.

## File overview

| File | Description |
|---|---|
| `snRNAseq_spatial_integrate.py` | Main analysis script for integrating frontal-lobe snRNA-seq and spatial transcriptomics data, predicting spatial cell types, and generating imputed spatial expression. |
| `README.md` | This documentation file. |

## Workflow summary

The script performs the following steps:

1. Load raw and processed frontal-lobe spatial transcriptomics AnnData objects.
2. Reconstruct a spatial AnnData object that combines raw expression with processed metadata and embeddings.
3. Load processed and raw adult cortex snRNA-seq AnnData objects.
4. Select snRNA-seq nuclei from the frontal lobe.
5. Identify genes shared between spatial and snRNA-seq datasets.
6. Normalize, log-transform, regress out total counts, and scale both datasets.
7. Concatenate the spatial and snRNA-seq objects.
8. Perform PCA followed by Harmony integration to reduce technology-specific effects.
9. Compute neighbors and UMAP on the Harmony-corrected representation.
10. Transfer snRNA-seq cell-type labels to spatial cells/spots by majority voting among nearest snRNA-seq neighbors.
11. Visualize predicted spatial cell types on t-SNE.
12. Impute spatial gene expression by averaging raw expression from nearest snRNA-seq neighbors.
13. Save the imputed spatial AnnData object.

## Required input files

The script expects the following files and directory structure:

```text
.
├── data
│   ├── adata_clusters2_noraw_v1.h5ad
│   └── adata_clusters2_raw.h5ad
├── save_data
│   ├── FL_s1_obje.h5ad
│   └── FL_stagate_v0.h5ad

```

### Input file descriptions

| Input file | Description | Required fields |
|---|---|---|
| `./save_data/FL_s1_obje.h5ad` | Raw frontal-lobe spatial transcriptomics AnnData object. | Raw expression matrix; gene metadata; `var['features']` should contain gene names. |
| `./save_data/FL_stagate_v0.h5ad` | Processed frontal-lobe spatial AnnData object, such as an object after STAGATE analysis. | Spatial cell/spot metadata; embeddings; `obs_names` matching a subset of `FL_s1_obje.h5ad`. |
| `./data/adata_clusters2_noraw_v1.h5ad` | Processed adult cortex snRNA-seq AnnData object. | `obs['MainLoc']`, `obs['clusters2_v1']`, UMAP embedding for visualization. |
| `./data/adata_clusters2_raw.h5ad` | Raw adult cortex snRNA-seq AnnData object. | Raw expression matrix and gene metadata. |

## Example installation

A typical conda environment can be created as follows:

```bash
conda create -n cortex_spatial_integration python=3.9 -y
conda activate cortex_spatial_integration
pip install scanpy harmonypy pandas numpy matplotlib seaborn scikit-learn tqdm
```

Depending on the system, additional dependencies for `scanpy` and `anndata` may be installed automatically.

## How to run

From the repository root, run:

```bash
python snRNAseq_spatial_integrate.py
```

The script uses relative paths, so it should be executed from the directory that contains the `data/` and `save_data/` folders.

## Output

The main output is:

```text
./save_data/FL_st_imputation.h5ad
```

This file contains an imputed spatial AnnData object with:

- `X`: imputed gene expression matrix for spatial cells/spots;
- `obs`: spatial metadata, including `Predict_cell_type`;
- `obsm`: spatial embeddings copied from the processed spatial object;
- `uns`: unstructured metadata copied from the processed spatial object;
- `var_names`: gene names inherited from the snRNA-seq reference.

## Key metadata generated by the script

| Field | Location | Description |
|---|---|---|
| `tech` | `obs` in preprocessed spatial and snRNA-seq objects | Technology label used for Harmony integration. Spatial cells are labeled `st_FL`; snRNA-seq cells are labeled `sc_FL`. |
| `dataset` | `combine_adata.obs` | Dataset label generated during concatenation. Values are `st` and `scrna`. |
| `Predict_cell_type` | `adata_FL_st.obs` and output object `obs` | Predicted spatial cell type assigned by nearest-neighbor majority voting from snRNA-seq labels. |

## Important implementation notes

### Gene matching

The script matches spatial and snRNA-seq features using the intersection of `var.index`. For the spatial object, `var.index` is set using:

```python
adata_FL_st.var = adata_FL_st.var.set_index('features')
```

Therefore, the spatial input object must contain a `features` column in `var`. If gene names are stored under another column, this line should be modified accordingly.

### Nearest-neighbor label transfer

The current script performs nearest-neighbor label transfer in integrated UMAP space:

```python
NearestNeighbors(...).fit(combine_adata_sc.obsm['X_umap'])
```

UMAP is useful for visualization but can be stochastic and may not be optimal for quantitative mapping. For a more stable analysis, users may consider performing nearest-neighbor search in the Harmony-corrected PCA space:

```python
combine_adata_sc.obsm['X_pca_harmony']
combine_adata_st.obsm['X_pca_harmony']
```

### Imputation strategy

For each spatial cell/spot, the script averages expression from its 20 nearest snRNA-seq neighbors. This is a simple nearest-neighbor imputation strategy and should be interpreted as a reference-guided estimate rather than direct spatial measurement.

### Potential fields required for plotting

The t-SNE visualization section assumes that the spatial AnnData object contains:

- t-SNE coordinates accessible to `sc.pl.tsne`;
- `obs['mclust']` for background visualization;
- `obs['Predict_cell_type']` for highlighting predicted labels.

If these fields are absent, the integration and imputation steps can still run, but the plotting section should be modified or skipped.

## Reproducibility recommendations

For improved reproducibility, consider adding the following checks before running the full workflow:

```python
assert 'features' in adata_FL_st.var.columns
assert 'MainLoc' in adata_FL_sc.obs.columns
assert 'clusters2_v1' in adata_FL_sc.obs.columns
assert adata_FL.n_obs <= adata_FL_raw.n_obs
```

It is also recommended to set a random seed before UMAP if exact figure reproducibility is required.
