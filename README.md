# Human_Cortex_Atlas

## Unveiling Molecular and Spatial Signatures of Regional Variations in the Human Brain

This repository contains the analysis code used in the manuscript **"Unveiling Molecular and Spatial Signatures of Regional Variations in the Human Brain"**. The workflow integrates adult human cortex single-nucleus RNA-seq and spatial transcriptomics data to characterize cortical regional specialization, annotate major neuronal and non-neuronal populations, compare cell-type composition across cortical regions, perform cross-species integration, evaluate cross-region reproducibility, conduct GWAS enrichment analysis, and map snRNA-seq-defined cell types onto spatial transcriptomics data.

## Study overview

Evolutionary adaptations in the human cerebral cortex have contributed to advanced cognitive abilities, yet the molecular and spatial organization of region-specific cortical cell types remains incompletely understood. In this study, we generated and analyzed a transcriptomic and spatial cell-type atlas of the adult human cortex, integrating single-nucleus transcriptomes and spatially mapped cortical cells across multiple cortical regions. The analyses identify region-associated neuronal and glial features, a region-specific GABAergic neuron subtype, differences in oligodendrocyte maturation, a primate-enriched Layer 4/5 IT neuron subtype, developmental programs linked to adult regional identity, and associations between neurological disease genetics, cortical regions, and cell types.

## Workflow

### 1. Preprocess raw snRNA-seq data

```bash
python 1.1_preprocess_scanpy.py
```

This script reads the 10x matrix, calculates mitochondrial fraction and total counts, merges sample metadata, filters cells and genes, detects doublets using Scrublet within each batch, normalizes and log-transforms the data, selects highly variable genes, regresses out technical covariates, performs PCA, applies BBKNN batch correction, runs UMAP and Leiden clustering, removes manually identified low-quality clusters, and exports metadata for Seurat.

### 2. Integrate and annotate snRNA-seq data in Seurat

```bash
Rscript 1.2_process_annotate_seurat.r
```

This script creates a Seurat object, adds metadata exported from Scanpy, integrates samples across locations, performs clustering, annotates excitatory neuron subclasses, and combines excitatory, inhibitory, and non-neuronal annotations into the final Seurat object.

Important implementation note: the original analysis environment included additional objects and palettes used in the final merge and plotting steps, including `ch.In`, `ch.Nn`, `ch.integrated.sub.sub`, and `gastrul_colors_37`. These should be generated or defined before running the corresponding sections.

### 3. Plot broad cell-class proportions across cortical regions

```bash
Rscript 1.3_cluster_fractions_across_regions.r
```

This script reads the final metadata table, calculates the relative abundance of glutamatergic, GABAergic, and non-neuronal classes for each cortical location, and plots mean proportions across anatomical regions.

### 4. Compute regional transcriptomic correlations

```bash
Rscript 1.4_region_correlation.r
```

This script identifies marker genes for excitatory subclasses, computes region-level average expression profiles, calculates pairwise regional correlations, and visualizes the results as correlation heatmaps.

### 5. Perform human-mouse cross-species integration

```bash
Rscript 1.5_integrate_region_across_species.r
```

This script integrates human frontal-lobe excitatory neurons with mouse frontal-region glutamatergic neurons, compares integrated clusters with species-specific labels, and visualizes cross-species cell-type relationships and proportions.

Important implementation note: users should confirm that metadata fields such as `source`, `cluster_level`, `clusters2_v1`, and `subclass_label` are present and correctly named in their Seurat objects before running this script.

### 6. Run MetaNeighbor analysis

```bash
Rscript 1.6_metaneighbor_analysis.r
```

This script converts the final Seurat object into a SingleCellExperiment object and performs MetaNeighbor one-vs-one analysis to evaluate cell-type reproducibility across cortical regions.

### 7. Generate CELLEX specificity scores

```bash
python 1.7_GWAS_1.py
```

This script calculates CELLEX expression specificity scores for combined cortical-region and cell-subclass labels. These scores are used as input to CELLECT-MAGMA for GWAS enrichment analysis.

### 8. Visualize GWAS enrichment results

```bash
Rscript 1.8_GWAS_2.r
```

This script reads CELLECT-MAGMA prioritization results, computes enrichment Z scores, adjusts P values, adds significance annotations, and generates a heatmap of GWAS-trait enrichment across region-by-cell-type labels.

### 9. Integrate snRNA-seq and spatial transcriptomics data

```bash
python snRNAseq_spatial_integrate.py
```

This script integrates frontal-lobe snRNA-seq and spatial transcriptomics data. It reconstructs a spatial AnnData object using raw expression and processed embeddings, filters the snRNA-seq reference to frontal-lobe cells, matches shared genes, normalizes and scales both datasets, performs PCA and Harmony integration, transfers snRNA-seq cell-type labels to spatial cells/spots by nearest-neighbor majority voting, and imputes spatial expression by averaging raw expression from nearest snRNA-seq neighbors.

Main output:

```text
./save_data/FL_st_imputation.h5ad
```

The output AnnData object contains imputed expression in `X`, spatial metadata in `obs`, predicted labels in `obs['Predict_cell_type']`, and spatial embeddings in `obsm`.

## Reproducibility and implementation notes

1. **Directory names are case-sensitive.** Some scripts use `Data/`, whereas others use `data/`. On Linux systems these are different directories. Keep the folder names consistent or update the paths in each script.
2. **Random seeds.** Exact reproduction of clustering, UMAP, subsampling, and downsampling may require explicit random seeds. For example, use `np.random.seed(123)` in Python and `set.seed(123)` in R.
3. **QC thresholds are dataset-specific.** In `1.1_preprocess_scanpy.py`, cells are retained if they contain 600 to 10,000 detected genes and have mitochondrial fraction below 20%. These thresholds should be evaluated using QC plots before being applied to other datasets.
4. **Manual low-quality cluster removal.** Leiden clusters `17` and `5` are removed as low-quality clusters in the preprocessing script. This decision should be supported by QC metrics and marker-gene inspection.
5. **Manual annotation.** Cell-type and subtype labels in `1.2_process_annotate_seurat.r` are based on cluster-level annotation. Users should verify annotations using canonical marker genes and supplementary marker tables.
6. **External resources.** MetaNeighbor and CELLECT-MAGMA analyses require external scripts, gene sets, and GWAS prioritization outputs that are expected under `./data/MetaNeighbor/` and `./data/CELLECT-MAGMA/`.
7. **Spatial label transfer.** `snRNAseq_spatial_integrate.py` performs nearest-neighbor label transfer in integrated UMAP space. UMAP is convenient for visualization but can be stochastic. For more stable quantitative mapping, users may consider nearest-neighbor matching in Harmony-corrected PCA space, such as `X_pca_harmony`.
8. **Spatial imputation.** Expression imputation averages raw expression from the 20 nearest snRNA-seq neighbors for each spatial cell/spot. These values should be interpreted as reference-guided estimates rather than directly measured spatial expression.
9. **Plotting fields.** The spatial plotting section assumes that the spatial object contains t-SNE coordinates and `obs['mclust']`. If these fields are absent, the plotting section can be skipped or modified without affecting integration and imputation.
